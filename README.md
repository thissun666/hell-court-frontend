# 阴曹地府论坛 · Hell Court Forum

> 一个以中国神话“地府”为背景的轻量级社区论坛，包含发帖、评论、点赞、收藏、关注、私信、公告、名气榜、留言墙及管理后台等功能。

## 📖 项目简介

“阴曹地府论坛”是一个带有中式奇幻色彩的社区平台。用户注册后可扮演地府中的角色，发布帖子、参与评论、互相关注、私信聊天、点赞收藏，并通过互动积累“名气值”登上排行榜。管理员可对内容进行审核、举报处理、发布系统公告等。

项目采用 **前后端不分离** 的架构：后端基于 Spring Boot 提供 RESTful API 与静态页面，前端使用原生 HTML/CSS/JavaScript 实现，数据存储使用 H2 文件数据库，开箱即用，适合个人学习与快速部署。

---

## ✨ 功能特性

### 用户端
- **注册 / 登录**：支持验证码、JWT 鉴权、登录日志记录。
- **发帖 / 评论 / 回复**：支持多级评论树、敏感词过滤、XSS 防护。
- **点赞 / 收藏**：帖子与评论均可点赞、收藏，状态实时切换。
- **关注 / 粉丝**：可关注其他用户，查看关注与粉丝列表。
- **好友系统**：发送好友请求、接受/拒绝、私信聊天。
- **通知中心**：点赞、评论、回复、@提及、好友请求、举报结果等消息通知。
- **名气排行榜**：根据互动量（点赞+评论）自动增加名气，展示排名。
- **留言墙**：弹幕式留言展示，支持实时滚动。
- **个人空间**：查看用户资料、发帖记录、关注/粉丝/收藏。
- **主题切换**：紫色幽冥、红黑血月、荧光赛博三种主题。

### 管理端
- **数据概览**：待处理举报、注册用户、帖子总数、未巡查评论。
- **举报管理**：查看、处理用户举报，反馈处理结果。
- **用户管理**：封禁/解封用户、查看登录日志。
- **评论巡查**：审核评论，删除违规内容。
- **公告管理**：发布、编辑、删除系统公告，用户端弹窗提示。
- **安全日记**：查看用户登录 IP 与时间。

## 🚀 本地运行

### 环境要求
- JDK 21+
- Maven 3.8+
- 可选：H2 数据库（已内嵌，无需额外安装）

### 步骤
1. **克隆仓库**
   ```bash
   git clone https://github.com/thissun666/hell-court-frontend.git
   cd hell-court-frontend
   ```

2. **修改配置**  
   编辑 `src/main/resources/application.properties`，按需修改数据库路径、JWT 密钥等：
   ```properties
   spring.datasource.url=jdbc:h2:file:./hell_db;DB_CLOSE_ON_EXIT=FALSE
   jwt.secret=${JWT_SECRET:please-change-me}
   server.port=8080
   ```

3. **启动应用**
   ```bash
   mvn spring-boot:run
   ```
   或打包后运行：
   ```bash
   mvn clean package
   java -jar target/*.jar
   ```

4. **访问**
   - 论坛首页：`http://localhost:8080/forum.html`
   - 登录页：`http://localhost:8080/login.html`
   - H2 控制台：`http://localhost:8080/h2-console`（JDBC URL: `jdbc:h2:file:./hell_db`）

> **初始管理员账号**：`admin` / `admin123`（首次启动自动创建，请及时修改密码）。
